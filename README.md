# Sahaya — Gemini-Powered Emergency & Safety Voice App

**Sahaya** is an AI-powered voice assistant designed for quick emergency response and assistance. It provides multi-language support to seamlessly guide users in critical situations, trigger quick alerts to trusted contacts, and locate nearby essential services.

---

## Key Features

- **Voice Assistance (Multilingual):** Interactive voice control supporting 11 languages with auto-localization (e.g., `en-IN`).
- **One-Tap Emergency Alert:** Fast SOS action to trigger alerts to designated trusted contacts and call emergency services (112).
- **Trusted Network Management:** Easily add and manage up to 3 emergency contacts.
- **Quick Service Locator:** One-touch access to find nearby police stations and hospitals.
- **Responsive & Accessible Design:** Clean mobile-first design with accessible UI components.

---

## Tech Stack

- **Frontend Framework:** React with TypeScript
- **Build Tool:** Vite
- **AI Integration:** Google Gemini API
- **Internationalization:** `i18next` (`src/i18n.ts`)
- **Styling:** Tailwind CSS / Modern CSS Modules
